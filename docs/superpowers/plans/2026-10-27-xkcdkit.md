# xkcdkit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship xkcdkit, a Python package with a library, CLI and TUI for xkcd comics backed by a local SQLite cache.

**Architecture:** Async fetchers in `sources.py` feed a pydantic `Comic` model into an insert-only SQLite `Store`. `AsyncXKCD` combines the two with freshness rules; `XKCD` wraps it synchronously. The CLI and TUI are thin layers over the client, and `render.py` owns terminal output.

**Tech Stack:** Python 3.12+, uv, httpx2, pydantic, typer, textual, textual-image, rapidfuzz, platformdirs, pytest, ruff, mypy, flake8, tox-uv, python-semantic-release.

**Spec:** `docs/superpowers/specs/2026-10-27-xkcdkit-design.md`

## Global Constraints

- Python `>=3.12`; test matrix 3.12, 3.13, 3.14, 3.15.
- Runtime deps only: typer, pydantic, textual, httpx2, textual-image, rapidfuzz, platformdirs.
- No underscore-prefixed module-level names. Every public function and class has a Google-style docstring.
- Functions short; source under about 800 lines excluding tests.
- Package `xkcdkit`, command `xkcd`, repo `eivl/xkcdkit` public.
- explainxkcd: descriptive User-Agent, 1 request per second during bulk sync.
- Comic rows are insert-only; `resync` replaces wholesale.

## Review Focus

1. Comic 404 does not exist on xkcd.com (the endpoint 404s). `get(404)` must raise `ComicNotFound`, and full sync must skip it without aborting. Test in Task 4.
2. xkcd JSON sometimes has non-ASCII and an empty `transcript`; models must accept empty strings and keep unicode. Test in Task 2.
3. explainxkcd page with `{{incomplete|...}}` and nested templates: `wikitext_to_text` must not leave braces or swallow the explanation. Test in Task 2.
4. Database file path's parent directory may not exist on first run; `Store` must create it. Test in Task 3.
5. `XKCD` (sync) called inside a running event loop must raise a clear `XKCDError`, not a cryptic `RuntimeError`. Test in Task 4.
